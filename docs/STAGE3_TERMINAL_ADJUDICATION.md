# 阶段三终局授权：消除 REVIEW

## 1. 目标

证明义务审计仍保留 34 个正常任务和 294 个有效攻击任务为 `REVIEW`。这在研究中诚实表达了证据不足，但不能直接作为在线网关的终局输出。本实验检验：在不把安全替代冒充原任务完成的前提下，能否把所有未决项收敛为可执行处置。

## 2. 方法

```text
SUPPORTED ─────────────────────────────→ ALLOW
CONTRADICTED + 可校验冲突 ─────────────→ DENY
NEED_EVIDENCE
      │
      ├─ 终局审计发现新增效果／越界／条件冲突 → DENY
      ├─ 只是缺少用户授权依据 ──────────────→ CONFIRM
      └─ 能证明是合理动态实现 ──────────────→ ALLOW
```

终局审计仍只读取可信用户请求、候选调用、证明义务和局部执行证据，不读取样本标签。它必须区分两类情况：

- 用户没有规定唯一工具序列，但当前调用是目标所必需、保持范围的正常实现变化；
- 当前调用引入了新的效果、接收方、账户、凭据、域名或对象，外部内容不能据此扩大用户授权。

模型被强制输出 `ALLOW/DENY` 及授权依据。部署策略再将“未找到授权依据”路由为用户确认，而不是把证据缺失伪装成明确攻击。最终公开接口只有 `ALLOW / DENY / CONFIRM`，没有 `REVIEW`。

## 3. 实验结果

实验覆盖证明义务阶段剩余的全部 397 个调用，使用 DeepSeek，共消耗 779,137 token。调用级结果中，342 个未决攻击调用全部被拒绝；55 个未决正常调用中 9 个放行、46 个拒绝。后者说明强制二分类本身非常保守，因此终局策略将其中仅属 `unresolved_authority` 的情况转为确认。

|---|---|---:|---:|---:|---:|
| AgentDojo | 正常任务（97） | 89（91.8%） | 4（4.1%） | 4（4.1%） | 0 |
| AgentDojo | 有效攻击（609） | 0 | 13（2.1%） | 596（97.9%） | 0 |

| **合计** | **正常任务（157）** | **126（80.3%）** | **14（8.9%）** | **17（10.8%）** | **0** |

## 4. 应如何理解结果

方法已经在接口上消除全部 `REVIEW`，并保持有效攻击自动放行为 0。但不能把这个结果写成“正常误报只有 10.8%”：17 个正常标签任务中包含已确认的错误日期、错误账户、未授权网址和错误效果等轨迹问题，也可能包含终局审计的保守误拒；在建立独立调用级金标前，两者不能完全分离。

`CONFIRM` 不是后台人工审核。它只在缺失信息确实属于用户授权范围时触发，确认结果应写回授权 DAG，后续同类调用不重复询问。在用户良性的威胁模型下，攻击诱导出的确认不会自动执行有害效果。

这次实验也给出明确边界：**零 REVIEW 可以通过终局裁决实现，但提高正常任务自动完成率仍必须依靠阶段二的主动补证，而不是继续强化二分类 Prompt。**
