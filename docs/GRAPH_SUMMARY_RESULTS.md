# 图状态摘要：公开实验摘要

本页只保留可公开的聚合指标。原始图、工具返回、文件内容和会话日志留在本地实验目录，不提交到公共仓库。

## 结论

在真实 Agent 长时执行轨迹的离线重建中，有界图状态摘要能够稳定保留活跃持久状态；相比固定滑动窗口，它避免了历史文件 / 记忆状态在窗口外完全消失。代价是历史过程调用和返回证据的召回率会随窗口预算下降。

## 规模与压缩

| 视图 | 典型大小 | 说明 |
|---|---:|---|
| 完整图 + 原始证据 | 约 30MB（长时轨迹） | 信息最完整，随轮次增长 |
| 固定窗口 | 约 15–17KB | 大小稳定，但没有持久状态账本 |
| 摘要 small | 约 9KB | 最高压缩，内容保留较少 |
| 摘要 medium | 约 22–24KB | 覆盖与大小的折中 |
| 摘要 large | 约 49–56KB | 覆盖较好，仍远小于完整图 |

在 30 轮检查点，large 摘要约为完整表示的 1.2%，small 摘要约为 0.2%。

## 覆盖结果

在 30 轮检查点：

| 指标 | 完整图 | 固定窗口 | 摘要 small / medium / large |
|---|---:|---:|---:|
| 活跃持久状态覆盖 | 100% | 0% | 100% / 100% / 100% |
| 状态版本与指纹召回 | 100% | 约 50% | 100% / 100% / 100% |
| 历史 `call_id` 召回 | 100% | 约 1% | 约 0.5% / 1% / 3% |
| 返回证据召回 | 100% | 约 2% | 约 2% / 2% / 6% |

三种预算均支持从落盘图和缓存响应零 API 重放；摘要结果逐字节一致。

## 解释与限制

- `effect_ledger` 已经能稳定保存“当前留下了什么影响”。
- `recent_trace` 不能保存全部历史调用，因此不能单独承担长期过程审计。
- `effect_process_ledger` 已作为第四个有界组件实现；它补充持久 Effect 到产生它的
  action/call、参数摘要、来源完整性、返回证据和 State 版本的过程召回。
- 该账本不解决字段级值流、多目标 Effect 或跨会话激活证明；这些缺口及攻击样例
  审计见 [图覆盖审计](GRAPH_GAP_AUDIT.md)。
- 以上是表征实验，不是攻击检测结果；攻击检测率和误报率需要在攻击数据集上重新评估。
