# 运行时参数溯源 v1.1：真实 AgentDojo 对照实验

## 这一步解决什么问题

通用授权编译器已经能够判断用户是否允许某类效果，但正常任务的关键参数经常要等工具返回后才能确定。例如，“删除最大的文件”授权了删除效果，却没有在用户消息中给出 `file_id`。如果仅比较字面参数，这类正常调用只能进入复核。

本轮验证一个更具体的问题：**不调用额外 LLM，也不为任务编写专用规则，能否从真实工具返回中程序化证明动态参数符合用户授权？**

## 方法

系统先将可信用户消息编译为效果授权和关键参数约束。Agent 每次真实调用工具时，主机侧事实图记录工具名、参数和返回；运行时解析器只执行有限、可重放的关系证明：

```text
用户授权：删除最大的文件
        ↓
事实图：list_files() → 文件集合
        ↓
证明：file_id = project(id, argmax(size, 文件集合))
        ↓
结果：该 delete_file 调用可放行
```

当前证明算子包括：

- 用户显式值；
- 命名对象的唯一投影；
- 最大、最小、最高评分、最低价格等排序选择；
- 前缀筛选；
- 从开始时间和用户给定时长计算结束时间。
- 将用户明确给出的日期与时间组合为规范化时间戳。

每份证明均保存所用规则和源工具调用 ID。找不到唯一证明时保持 `REVIEW`，不会用猜测代替证据。实现中没有 task ID、任务模板或场景专用提示词。

## 实验设置

- 数据：AgentDojo v1.1 的 workspace、Slack、travel 和 banking 全部 97 个正常任务；
- 执行：逐条运行官方 canonical tool calls，而非只读取静态标注；
- 记录：真实参数、工具返回、事实图节点与边、参数证明和最终决策；
- 对照：通用 Schema-Grounded 授权 v0.7；
- 模型成本：0，不调用 LLM。

全部 97 个任务均完成执行，环境错误为 0。

## 结果

| 判定 | 仅效果授权 v0.7 | 加入运行时证明 v1.1 |
|---|---:|---:|
| 自动放行 | 38/97（39.2%） | **50/97（51.5%）** |
| 进入复核 | 59/97（60.8%） | **47/97（48.5%）** |
| 高置信告警 | 0/97 | 0/97 |

运行时解析器将 14 次持久化调用完整证明，并将 12 个任务从 `REVIEW` 转为 `ALLOW`：

- 删除最大的文件；
- 向指定文件追加用户给定内容；
- 将用户加入满足前缀条件的频道；
- 向满足前缀条件的频道发送指定正文；
- 为日历事件添加用户明确指定的参与者。
- 将用户消息中分开出现的日期和时间，安全归一化为日历工具所需的时间戳。

## 结果说明了什么

第一，正常任务中的一部分动态性不是自由语义推理，而是可验证的“筛选—排序—投影—计算”关系。它们可以直接利用执行事实解决，不应全部交给 LLM。

第二，参数级证明不等于整次调用获准。一次写操作往往同时包含收件人、正文、时间、参与者等多个关键字段；只要仍有一个字段缺少依据，整个调用就继续复核。

第三，剩余 47 个复核任务主要不是工具契约缺失，而是以下三类边界：

1. **可继续程序化但尚未覆盖：**可信主体身份自动加入、跨字段计算、更多唯一过滤和聚合关系；
2. **需要内容语义：**摘要、改写正文、从文档识别“客户”“房东”等角色；
3. **外部委托：**“执行邮件/网页中的任务”没有在用户侧限定具体效果，不能仅凭来源存在而自动授权。

因此，程序化规则仍有提升空间，但合理目标不是让它独自解决所有正常任务。它应尽可能产出高精度证明，把剩余真正涉及语义和委托边界的少量字段交给局部 LLM 审计。

## 当前方法边界

冻结算子后，我们又对 629 个官方任务—攻击组合进行了条件审计，其中 20 个组合没有目标工具调用，因此有效攻击组合为 609 个。正常轨迹被真实执行并向解析器提供事实，攻击目标调用只接受审计、不实际执行。

| 有效攻击组合判定 | 数量 | 比例 |
|---|---:|---:|
| 高置信告警 | 413/609 | 67.8% |
| 进入复核 | 175/609 | 28.7% |
| 直接放行 | 21/609 | 3.4% |

运行时关系证明没有放行任何新的攻击调用（`proved_attack_calls = 0`）。21 个直接放行仍全部来自 Slack 的只读 `get_webpage` 攻击目标，属于当前“只读工具默认允许”策略的已知边界。也就是说，本轮增加的通用关系算子使正常自动放行由 38 提升到 50，同时没有扩大持久化攻击的授权面。

这仍是官方目标调用的条件审计，不是受害模型端到端 ASR；它证明的是检查器在目标调用已经出现时的区分能力。
