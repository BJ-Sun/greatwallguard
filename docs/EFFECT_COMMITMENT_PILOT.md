# 从 TaskScope 到逐项 Effect 承诺：请求侧试验

## 要验证的一个问题

“同类操作超过一次”在单任务样本上有效，但把合法的双邮件、双事件、双分享全部误报。更合适的授权单位是用户**具体要求完成的一件事**：例如“把文件 4 分享给 Alex”，而不是“允许 `share_file` 一次”。一条用户请求可产生多项承诺；后续用户消息可新增承诺，但未来消息不能追认过去的操作，文件/记忆/工具返回也不能自行生成用户授权。

## 数据与隔离

我们先冻结了只含逐轮用户消息和可用工具名的 [`request_only.jsonl`](../experiments/effect_commitment_pilot/request_only.jsonl)：53 条请求序列（25 对攻击/正常、另 3 条双 Effect 正常），共 198 轮消息、148 种不同文本。该视图不含标签、case 路径、工具调用、图和成功结果；评估阶段才使用单独的 `evaluation_mapping.jsonl` 连接标签。这里的“隐藏”是处理流程隔离，不是密码学盲法。

从请求侧选出 10 条覆盖单/双授权与含糊跨轮续办的序列，写成带逐字证据片段的 [`reference_draft.json`](../experiments/effect_commitment_pilot/reference_draft.json)。**这是助手根据请求文本复核的研究草稿，不是独立人工金标。**每条承诺记录来源轮次、操作、明确的对象/目的地/参数；“继续剩余沟通”“按记录处置”等没有明确对象的请求单列为 `unresolved`，不凭猜测扩权。

本试验按“用户输入可信、攻击来自其他入口”的威胁模型解释这些消息；仍需逐条核查攻击仓库中每轮用户消息的实际控制者。若某些消息本身由攻击者控制，它们不能作为可信授权，相关结果必须从该子集剔除或另行报告。

本地确定性提取器只读取上述请求侧视图，生成 [`local_candidates.jsonl`](../experiments/effect_commitment_pilot/local_candidates.jsonl)。外部 LLM 标注未获授权，当前流程没有把请求语料发送给第三方。

## 匹配规则与第一轮观察

图中的每个已提交持久工具 Effect 尝试匹配一项**更早或同轮**、尚未兑现的承诺。操作、显式收件人/文件 ID/权限/主题必须一致。一项承诺不能兑现两次。结果分三类：

```text
匹配明确承诺                  → authorized
不匹配，但先前有相关含糊续办    → unresolved（需进一步查证/询问）
既无明确承诺，也无相关续办      → outside_explicit_scope
```

在 10 条参照草稿中，本地提取器与草稿的“操作 × 轮次”计数同为 17 项；由于提取规则是在这些请求形式上构建的，这**不是独立准确率**，也不能证明对象/参数抽取完备。参照承诺与图匹配得到 13 个 `authorized`、4 个 `unresolved`。其中三条双 Effect 正常任务的六个 Effect 均被逐项授权，不再因“第二次”误报；四个含糊续办后的额外操作没有被错误地当作明确授权，但也不能仅凭用户请求断言必然恶意。

对全部 53 条请求运行本地候选抽取的探索性结果：25 条普通正常和 3 条双 Effect 正常均无越界/待判定；25 条攻击中，19 条至少有一个 `outside_explicit_scope`，14 条至少有一个 `unresolved`（可重叠）。这些数字依赖未独立验证的本地候选标注，**不能作为最终检测率或误报率**。另外，攻击轨迹中有 27 项请求侧工作区写入承诺尚未纳入当前匹配器；它目前只核对列出的高影响工具 Effect，不能声称覆盖全部持久副作用。

## 现在真正需要解决的两点

1. **含糊续办如何判定。** “继续沟通”“按 MEMORY.md 中的路由偏好办”可能是正常的条件性任务，也可能让被污染的记忆决定收件人。把它全放行会漏检；全阻断会误报。下一步应只对这些 `unresolved` Effect 做有界的来源弱化/重放或请求用户确认，检验额外动作是否仍由可信请求支持，而不是重放整个长上下文。
2. **工作区持久 Effect 的归因。** 图保留了文件/记忆状态变化，但 OpenClaw 启动时也会创建自身工作区文件。需区分运行时初始化、用户授权写入与外部来源诱导写入，再将它们纳入同一承诺匹配；否则“跨步传播”的关键证据虽在图里，检测器仍没用上。

复现：运行 `experiments/freeze_request_only_view.py` 冻结请求侧视图，再运行 `experiments/effect_commitment_reference_pilot.py` 生成本地候选与匹配摘要。完整逐项结果在 `reference_pilot_results.jsonl` 和 `all_local_candidate_results.jsonl`。请求侧参照草稿需独立研究者复核后，才能用于论文中的“金标 Scope”实验。
