# 在线 Effect 检查：先告警，再识别可能误报

## 目标与决策点

检测必须发生在**工具执行前**，不能等事后图中出现成功的 Effect 才判断。原型为每个拟执行的工具调用输出三种结果：

| 结果 | 含义 | 当前建议处理 |
|---|---|---|
| `allow` | 与此前可信用户消息中的明确操作和已绑定参数匹配 | 放行 |
| `review` | 可疑，但正常任务也可能需要它；同时输出具体的不确定原因 | 告警、记录证据，必要时询问用户；目前不自动阻断 |
| `alert` | 未找到对应的用户任务承诺，也没有已识别的含糊续办理由 | 高优先级告警；目前仍不声称可以安全自动阻断 |

状态机只让**可信用户消息**增加任务授权；工具返回、文件和记忆不能增加授权。调用前预留一个明确承诺，调用成功后才消耗，失败则释放以允许重试。每个 Effect 对应一个承诺，因而两个明确授权的发送不会被全局“一次调用”限制误报。

```text
可信用户输入 ──提取明确承诺/含糊需求──> 当前任务状态
                                           │
拟执行工具 + 参数 ──调用前核对─────────────> allow / review / alert
                                           │
工具成功/失败 ──只在成功时消耗承诺─────────> 下一步任务状态
```

`review` 的“可能误报”并非事后利用标签判定，而是在线可见的证据缺口：对象需从任务数据中解析、邮件正文未被用户明确绑定、日历细节未绑定、含糊续办、工具 Effect 尚无映射，或当前解析器不支持这类授权。它是**复核优先级提示，不是正常概率**。目前没有自动把这类告警消除。

## 已完成的因果回放

使用已有真实 Agent 执行轨迹，按轮喂入用户消息，在每次记录的工具调用**之前**判断，只在记录的调用成功后更新状态。检测器看不到攻击标签、攻击目标、最终成败、oracle 或未来消息；这些仅在判断完成后做分组统计。没有重新攻击，也没有执行真实邮件/文件操作。回放暂把 `visible_agent_turns.user_message` 当作可信用户输入；部分攻击 case 的这些消息由场景脚本生成，真实性尚未独立审定，因此这也是评估边界。

| 分组 | 触发任意告警的 case | 其中标为“可能误报” | 说明 |
|---|---:|---:|---|
| 25 个匹配的双成功攻击 | 24/25 | 24/25 | 22 个有持久目标工具调用的 case，目标调用均在执行前触发告警；另外 2 个输出完整性 case 的告警来自其他未映射工具，**不代表输出攻击被识别** |
| 25 个匹配正常任务 | 4/25 | 4/25 | 均为 `review`，无 `alert` |
| 3 个双操作正常任务 | 2/3 | 2/3 | 均为 `review`，说明复杂正常步骤确会告警 |
| 14 个独立的明确授权控制 | 3/14 | 3/14 | **只统计被确认授权的目标操作**；3 个删除调用因解析器未识别授权而误报，均被标成可能误报 |

14 个控制 case 的其他工具调用不一定已被独立审定为正常，因此不能把整条 trace 上的全部告警当作假阳性。以上样本规模也不足以估计真实部署误报率。对有持久目标工具调用的攻击，目标调用前告警为 **22/22**；对输出完整性目标则没有相应检测能力。24/25 仅是整条 trace 上的任意告警覆盖，不能当成攻击检测召回，更不是阻断成功率；其中只有 4 个 case 出现较高优先级 `alert`。多数攻击与正常复杂操作都落在 `review`，因此当前机制还不能自动分开它们。

## 当前能做、不能做

原型代码在 [`experiments/online_effect_guard.py`](../experiments/online_effect_guard.py)，评估入口在 [`experiments/evaluate_online_effect_guard.py`](../experiments/evaluate_online_effect_guard.py)。接口是 `on_user_message`、`before_tool_call`、`after_tool_result`，可接在工具网关调用前；**目前只是已保存轨迹的因果回放，尚未接入实际 OpenClaw 在线运行**。

本版只维护有限的操作/参数承诺状态，**尚未读取完整跨轮状态图进行判定**。下一步应在现有图的 Action→Effect→State 记录上挂接这三个回调，并特别验证：从可信任务数据解析出的对象和内容，何时足以把 `review` 降为 `allow`；来源不可信时不能借这种解析扩大授权。未知工具目前保守地进入 `review`，不能视为已完成 Effect 覆盖。输出完整性攻击也不在此工具调用前检查的能力范围。

复现：

```bash
PYTHONPATH=src:experiments ../attack-generation/openclaw-agentlab/.venv/bin/python -m unittest experiments.test_online_effect_guard -q
../attack-generation/openclaw-agentlab/.venv/bin/python experiments/evaluate_online_effect_guard.py
```
